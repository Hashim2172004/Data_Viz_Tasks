# Week 1 submission

Open **week1_assignment_completed.ipynb** for the completed four exercises from Part 6 of the supplied lecture.
The notebook is executed, so the answers and figures are visible immediately.

## Run locally
1. Extract the ZIP completely.
2. Open a terminal in this folder.
3. Run `python -m pip install -r requirements.txt`.
4. Run `python -m jupyter notebook` and open `week1_assignment_completed.ipynb`.
5. Use Kernel → Restart Kernel and Run All Cells.

The data is bundled; no internet access is required to rerun the analysis.
Alternatively run `python week1_assignment_completed.py` from this folder.

- `week1_assignment_completed.ipynb`: complete solution with executed outputs.
- `week1_assignment_completed.py`: script equivalent.
- `week1_visualization.ipynb`: supplied lecture, executed against included datasets.
